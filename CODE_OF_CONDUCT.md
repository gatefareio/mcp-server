# Code of Conduct

We're using the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as our community standard. Be kind, assume good faith, don't make people feel
unwelcome.

## Reporting

If something happens in this project's space (issues, PRs, discussions) that
violates the Covenant, email [support@gatefare.io](mailto:support@gatefare.io).
Reports stay private.

We respond to credible reports within 72 hours. Outcomes range from a private
note to a permanent ban, depending on severity. We don't owe anyone a public
explanation of moderation decisions.

## Scope

This Code applies to project spaces (this GitHub repo, the `@gatefare/mcp`
npm package, our Discord channel if/when one exists). It does not extend to
private interactions between project participants outside those venues.
